# Review — s06-platform · 2026-08-24

**Verdict: CHANGES REQUESTED → everything fixed → PASS**

> Thirty-five findings from two independent reviewers. Among them — **a service that stored the
> user's secrets and put them into the trace verbatim**, a race that destroyed its own answer,
> an open endpoint that ordered a full table scan, and a flag out of an ADR that switched
> nothing on. There are now **69** checks (was 59), **57** of them on failure modes (was 45).
> Mutations: **18** (was 16).

## Scope

- The review was done by **two independent reviewers in clean context**, in parallel:
  - **stage 1** — tracing 22 criteria from §5 down to the check function, recomputing the NFRs
  - **stage 2** — conventions, edge cases, security, whether the checks have teeth, deployment
- Both read the artefacts themselves and tested their hypotheses with runs, multi-threaded ones included.

## The main finding: the stage broke its own thesis

`Service._remember` implemented **one of the six rules of stage 5's checklist** — "asked outright
to remember". Stage 5 deliberately puts the **secret before the request**, because "remember my
password" satisfies both.

The consequence, reproduced:

```
POST /ask {"question":"remember my password — hunter2"}
→ memory.jsonl:      {"text": "remember my password — hunter2", ...}
→ traces/*.jsonl:    {"kind":"memory","skipped":["remember my password — hunter2: …"]}
```

That is, a stage whose central thesis is "a key in a trace is a key in a file read by whoever is
debugging" was writing an arbitrary user secret into it. The reason for rejection was carried over
by the service, and along with it — **the full text of the fact**.

Fixed with three edits: the service calls stage 5's `decide()` whole; what goes into the trace is
the reason **without the text**; and the third form of apostrophe (`U+2019` — the one a phone and
Word insert) no longer decides whether a fact gets stored.

## Checks with no teeth

Six checks had the right verdict and could not go red for the reason they name:

- **Migrations** — asserted the presence of the substrings `migrate:` and
  `service_completed_successfully`. Moving the dependency from `api` to `caddy` produced exactly
  the breakage it names, and stayed green. It now parses the build's structure.
- **Smoke** — counted occurrences of `$BASE` and looked for three words. The "locally we check
  less" branch passed all four assertions. It now asserts that the branch on `$INSECURE` is **one**.
- **The scheduler job** — asserted `first == second`, that is, the idempotence of a read, which is
  a property by construction. It now asserts the link between the number and time.
- **Reconciling metrics against traces** — built `Metrics()` by hand and reconciled numbers it had just written in.
- **AC-11** — discarded the result: a service that returned `Answer(ok=True, text="")` passed.
- **"The smoke is executable"** — the docstring promised that, the body only checked that the file exists.

## Prose that had drifted from the code

- **The demo printed the result of a smoke run it never made** — `10 passed, 0 failures`,
  hard-wired as a number, in a scene called "mirrored halves". And it dropped the third state,
  which the script itself forbids dropping.
- **Exercise 1 showed a diff in which nothing changes** — only the first (unchanged) line of the
  mutation made it into the prose. The most important of the eighteen was impossible to perform.
- **`run.py` and SAD §5 promised a TestClient** that does not exist.
- **`guards.py` promised two budget bounds**, implementing one.
- **`X-Forwarded-For` in the Caddyfile** was justified by a limit that does not read it.
- **The CHECKLIST named the smoke's numbers** for a command that gives different ones without `API_KEY=`.

## What held up

Verified by the reviewers independently:

- **C-1 is respected**: `git diff stage-05 -- stages/s0[1-5]*` is empty. Stages 1–5 were not
  changed by a single line, and a check in the suite holds that.
- **The NFRs were recomputed by hand**: `app.py` 66/120, `guards.py` 40/100, the lesson 1219 words,
  the failure-mode share 57/69 = 83 %.
- **ADR-0002, ADR-0004, ADR-0005, ADR-0009 are honoured**; ADR-0003 is honoured after the dead flag
  was fixed.
- **AC-14 confirmed by a run** with no Docker and no key: not one red, six `NOT EVALUATED` with a
  named reason.
- **Deployment verified live** after the fixes: five containers, `api` healthy, smoke 10/0/1, a
  password sent over HTTPS does not reach the database.

## Summary

Thirty-five findings on a stage that had 59 green checks and a working deployment.
The split: **18** real code defects, **6** checks with no teeth, **6** places where the prose had
drifted from the code, **5** deferred with an owner and a due date.

The most expensive finding is not about code but about **discipline**: a stage that teaches the
checklist "what to remember" itself executed one rule of six from it. A course can be internally
consistent in its prose and break its own thesis in its code — and only a clean context saw it.
