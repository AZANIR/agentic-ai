# T4 — Three guards: key, rate, budget — three different refusals

- **Layer:** `app`
- **Deps:** T1
- **Criteria:** [AC-03](../spec.md), [AC-03b](../spec.md), [AC-12](../spec.md), [AC-13](../spec.md)
- **Touches:** `stages/s06_platform/guards.py`

## Why

Three mechanisms, not "security". The order is not arbitrary: first **who**, then **how many**,
then **at whose expense**.

**The mirrored half is mandatory.** A guard that lets nobody through satisfies AC-03 completely
and is broken while doing so — the course has caught this shape already at stages 1, 2, 3 and 5.

The key comparison is constant-time (ADR-0006). A plain `==` finishes at the first differing
byte and gives away the length of the shared prefix through the response time.

## Definition of Done

Every refusal differs from the others both in the response and in the metrics; none of them reaches the model; the key appears neither in the log, nor in the trace, nor in the response
