# T5 — Intent classifier: one branch per one call

- **Layer:** `app`
- **Deps:** none
- **Criteria:** [AC-01](../spec.md)
- **Touches:** `stages/s06_platform/intent.py`

## Why

A cheap replacement for the supervisor (ADR-0001): one call instead of two and more.

**The boundary is named with a number.** The classifier gets it wrong on requests that touch two
branches at once. The lesson has to show that share measured on a set rather than estimate it in
words — otherwise "the trade-off is named honestly" stays a claim.

## Definition of Done

Three different requests give three different branches; the branch lands in the trace as the first step; the error on a compound request is named with a number, not with words
