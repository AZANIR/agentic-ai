# T5 — Класифікатор наміру: одна гілка за один виклик

- **Шар:** `app`
- **Залежить від:** нічого
- **Критерії:** [AC-01](../spec.md)
- **Торкається:** `stages/s06_platform/intent.py`

## Навіщо

Дешева заміна supervisor (ADR-0001): один виклик замість двох і більше.

**Межа називається числом.** Класифікатор помиляється на запитах, що стосуються двох
гілок одночасно. Урок має показати цю частку заміряною на наборі, а не оцінити словами —
інакше «компроміс названо чесно» лишиться заявою.

## Definition of Done

Три різні запити дають три різні гілки; гілка потрапляє у трейс першим кроком; помилка на складеному запиті названа числом, а не словами
