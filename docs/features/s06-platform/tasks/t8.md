# T8 — The two-worker trap: the scheduler inside and on its own

- **Layer:** `app`
- **Deps:** T7
- **Criteria:** [AC-07](../spec.md), [AC-07b](../spec.md)
- **Touches:** `stages/s06_platform/jobs.py`

## Why

The trap stays in the repository **behind a flag, not in a comment** (ADR-0003). The exercise
turns the scheduler on inside the application, the Learner sees the number "2", turns it off and
sees "1".

**The second half matters more than the first.** A doubled job is visible in the logs; a doubled
limit is visible nowhere — the service behaves normally, the boundary merely means twice as much
(AC-07b).

## Definition of Done

With the flag on, the job runs twice per interval and that is visible as a number; with it off — once; the same pair is proved for the rate limit
