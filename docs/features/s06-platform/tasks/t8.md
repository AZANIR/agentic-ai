# T8 — Пастка двох воркерів: планувальник усередині й окремо

- **Шар:** `app`
- **Залежить від:** T7
- **Критерії:** [AC-07](../spec.md), [AC-07b](../spec.md)
- **Торкається:** `stages/s06_platform/jobs.py`

## Навіщо

Пастка лишається в репозиторії **під прапорцем, а не в коментарі** (ADR-0003). Вправа
вмикає планувальник усередині застосунку, читач бачить число «2», вимикає й бачить «1».

**Друга половина важливіша за першу.** Подвоєну задачу видно в логах; подвоєний ліміт не
видно ніде — сервіс поводиться нормально, просто межа означає вдвічі більше (AC-07b).

## Definition of Done

З увімкненим прапорцем задача виконується двічі за інтервал і це видно числом; з вимкненим — один раз; та сама пара доводиться для ліміту частоти
