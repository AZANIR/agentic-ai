# T1 — Counter factory: in memory and in a shared store behind one contract

- **Layer:** `infra`
- **Deps:** none
- **Criteria:** [AC-04](../spec.md), [AC-04b](../spec.md), [AC-05](../spec.md), [AC-05b](../spec.md), [AC-07b](../spec.md)
- **Touches:** `shared/counters.py`

## Why

The rate counter and the spend counter are the same in mechanics and different in meaning. One
structure with two windows: a minute for the rate, a day for the budget.

**What matters here is not the implementation but the contract.** Two implementations mean two
behaviours, and a check has to assert what is common to both. The most important assertion:
**two independent instances, created separately, see one number**. It is green on a shared store
and red on a process-local one — which is exactly what tells the two apart (ADR-0002).

## Definition of Done

Both implementations pass one set of assertions about the contract; the check that two independent instances see one number goes red on the process-local implementation
