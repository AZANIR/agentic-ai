# T1 — Фабрика лічильників: у пам'яті й у спільному сховищі за одним контрактом

- **Шар:** `infra`
- **Залежить від:** нічого
- **Критерії:** [AC-04](../spec.md), [AC-04b](../spec.md), [AC-05](../spec.md), [AC-05b](../spec.md), [AC-07b](../spec.md)
- **Торкається:** `shared/counters.py`

## Навіщо

Лічильник частоти й лічильник витрат — те саме за механікою і різне за змістом. Одна
структура з двома вікнами: хвилина для частоти, доба для бюджету.

**Головне тут — не реалізація, а контракт.** Дві реалізації означають дві поведінки, і
перевірка має стверджувати те, що спільне. Найважливіше твердження: **два незалежні
екземпляри, створені окремо, бачать одне число**. Воно зелене на спільному сховищі й
червоне на процесо-локальному — тобто саме воно й відрізняє їх (ADR-0002).

## Definition of Done

Обидві реалізації проходять один набір тверджень про контракт; перевірка, що два незалежні екземпляри бачать одне число, червоніє на процесо-локальній реалізації
