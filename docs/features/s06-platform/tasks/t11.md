## Why

**The question to every check:** what exactly has to break for it to go red? At stage 5 the
review found four for which the answer was "nothing".

A check that needs a container says so in words (`NotVerified`) rather than failing.

## Definition of Done

Each of the 22 criteria has a check; the share of failure modes is ≥ 1/3; the set is green or NOT EVALUATED without Docker, none red; every mutation is caught by a check that asserts about it
