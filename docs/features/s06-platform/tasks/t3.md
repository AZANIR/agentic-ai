# T3 — Migration: a facts table with the owner in the key

- **Layer:** `migration`
- **Deps:** T2
- **Criteria:** [AC-10](../spec.md)
- **Touches:** `docs/features/s06-platform/migrations/`

## Why

A table arrives together with the stage that needs it — so says `migrations/0001_init`.

The owner filter becomes a condition of the query, and that closes the debt named in stage 5's
ADR-0004: the file implementation read **every** record, other people's included, and filtered
in memory.

## Definition of Done

The migration applies and rolls back cleanly; the owner filter is a condition of the query, not filtering in memory
