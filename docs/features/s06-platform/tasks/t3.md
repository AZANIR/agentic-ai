# T3 — Міграція: таблиця фактів із власником у ключі

- **Шар:** `migration`
- **Залежить від:** T2
- **Критерії:** [AC-10](../spec.md)
- **Торкається:** `docs/features/s06-platform/migrations/`

## Навіщо

Таблиця приходить разом з етапом, якому потрібна, — так каже `migrations/0001_init`.

Фільтр власника стає умовою запиту, і це закриває борг, названий в ADR-0004 етапу 5:
файлова реалізація читала **всі** записи, зокрема чужі, і фільтрувала в пам'яті.

## Definition of Done

Міграція застосовується й відкочується чисто; фільтр власника — умова запиту, а не фільтрація в пам'яті
