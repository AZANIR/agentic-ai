# T2 — Фабрика сховища фактів: файл етапу 5 і база за одним набором методів

- **Шар:** `infra`
- **Залежить від:** нічого
- **Критерії:** [AC-03c](../spec.md), [AC-10](../spec.md)
- **Торкається:** `shared/factstore.py`

## Навіщо

Етап 5 обіцяв, що сховище можна замінити «тим самим інтерфейсом». ADR-0004 показав, що
обіцянка виконується наполовину: набір методів справді вузький, але `Memory` приймає
**шлях**, а не сховище, тож підмінити реалізацію всередині етапу 5 без правки неможливо.

Тому фабрика стоїть **зовні**: файлову реалізацію бере як є, а контракт, спільний для
обох, стверджує етап 6. Ізоляція власників перевіряється **на обох** — інакше `WHERE`
лишиться неперевіреним рівно там, де він і є новим кодом.

## Definition of Done

Обидві реалізації проходять один набір тверджень; етап 5 не змінено жодним рядком, його 42 перевірки лишаються зеленими
