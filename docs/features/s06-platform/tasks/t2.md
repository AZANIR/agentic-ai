# T2 — Fact store factory: stage 5's file and a database behind one set of methods

- **Layer:** `infra`
- **Deps:** none
- **Criteria:** [AC-03c](../spec.md), [AC-10](../spec.md)
- **Touches:** `shared/factstore.py`

## Why

Stage 5 promised the store could be swapped out "behind the same interface". ADR-0004 showed
the promise is kept by half: the set of methods really is narrow, but `Memory` takes a **path**
rather than a store, so swapping the implementation inside stage 5 is impossible without editing it.

That is why the factory stands **outside**: it takes the file implementation as it is, and the
contract common to both is asserted by stage 6. Owner isolation is checked **on both** —
otherwise `WHERE` stays unchecked at exactly the place where it is the new code.

## Definition of Done

Both implementations pass one set of assertions; stage 5 is not changed by a single line, its 42 checks stay green
