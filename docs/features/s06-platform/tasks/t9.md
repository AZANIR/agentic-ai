# T9 — Deployment: a production build, a proxy with TLS, a check script

- **Layer:** `infra`
- **Deps:** T7, T8
- **Criteria:** [AC-08](../spec.md), [AC-09](../spec.md), [AC-09b](../spec.md)
- **Touches:** `deploy/docker-compose.prod.yml`, `deploy/Caddyfile`, `deploy/smoke.sh`, `deploy/RUNBOOK.md`

## Why

The script has to be **the same** for both targets: the list of checks does not depend on where
it is looking. Otherwise the local run proves something other than the run against the domain.

There is no real VM (C-3). The mechanics are checked locally; trust in a certificate from a
public authority stays a third state — `NOT EVALUATED`, not green with a stretch.

## Definition of Done

smoke.sh runs the same list against localhost and against the domain, gives zero on a healthy build and non-zero on a broken one; the public certificate check is marked NOT EVALUATED without a machine
