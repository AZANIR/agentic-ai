## Навіщо

Скрипт має бути **однаковим** для обох цілей: перелік перевірок не залежить від того,
куди він дивиться. Інакше локальний прогін доводить не те, що прогін на домені.

Реальної VM немає (C-3). Механіка перевіряється локально; довіра до сертифіката від
публічного центру лишається третім станом — `НЕ ПЕРЕВІРЕНО`, не зеленим із натяжкою.

## Definition of Done

smoke.sh виконує той самий перелік проти localhost і проти домену, дає нуль на справній збірці й ненуль на зламаній; перевірка публічного сертифіката позначена НЕ ПЕРЕВІРЕНО без машини
