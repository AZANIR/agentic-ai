## Why

Five stages are stitched together here — **without a single edit inside any of them** (C-1).

The trace's boundary is named up front (ADR-0005): stages 2 and 5 write no steps, so the trace
answers "which branch" and does not answer "why these documents exactly". That is written into
AC-02 rather than discovered at stage 8.

## Definition of Done
