# T1 — Адаптер ембеддингів у спільному шарі: hash | fastembed | openai

## Why

Ембеддер — такий самий профіле-залежний адаптер, як LLM-клієнт ([ADR репозиторію 0002](../../../adr/0002-profile-switched-adapters.md)). Навчальний дефолт — хеш за словами ([ADR-0001](../adr/0001-word-hash-embedder-as-the-teaching-default.md)).

## What

`shared/embeddings.py`: `get_embedder()` за тим самим зразком, що `get_client()`. Хеш за словами — детермінований, stdlib плюс NumPy, без мережі. `fastembed` і `openai` — за тим самим інтерфейсом, вмикаються конфігурацією. Плюс рядок для спільного банера джерел, щоб не з'явився другий банер поруч із банером етапу 1.

## Definition of Done

- [ ] Хеш-ембеддер детермінований: той самий текст дає той самий вектор між процесами
- [ ] Вектори нормовані — косинус зводиться до скалярного добутку
- [ ] З підробленим оточенням фабрика повертає справжній ембеддер і називає його
- [ ] Без налаштувань не робить жодного мережевого звернення
- [ ] `python -m shared.check` лишається зеленим
- [ ] lint чистий

## Notes

Українська морфологія: «повернення» й «повернень» для цього ембеддера різні слова. Це матеріал уроку, не баг — але поведінку зафіксувати перевіркою.
