# T7 — Урок етапу: канон статті, міст на NovaShop, «що зламати»

## Why

Головний артефакт етапу: код без уроку не вчить. Структура — [CONVENTIONS.md](../../../../CONVENTIONS.md).

## What

`README.md` (UA): що зможеш після етапу → канон зі статті (погода) → міст на NovaShop → три захисні механізми, кожен із поясненням «чому» → що зламати. Порядок читання файлів заданий явно. Обов'язково: чесний ручний чекліст для AC-05 і межа власної валідації (вкладені об'єкти не підтримуються). `README.en.md` — один екран: що це, як запустити, чого навчить.

## Definition of Done

- [ ] Урок ≤ 2500 слів (spec §6: ≤ 25 хв читання)
- [ ] Порядок читання чотирьох модулів заданий явно
- [ ] Кожен із трьох захистів має абзац «навіщо», а не лише «як»
- [ ] Ручний чекліст для справжнього провайдера присутній
- [ ] Межі власної валідації названі прямо
- [ ] Усі посилання резолвляться
