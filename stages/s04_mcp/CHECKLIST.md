## Я зрозумів

- [ ] Можу назвати три ролі — host / client / server — і сказати, хто з них ким володіє.
- [ ] Можу пояснити, що саме змінює `list_tools()`, і чому це важливіше за зручність.
- [ ] Розумію, чому `json.loads` на всій відповіді ламається, і чому регулярка гірша за нього.
- [ ] Можу назвати три фази відмови й сказати, чому їх не можна зливати в одну.
- [ ] Можу пояснити, що лишається за клієнтом, коли інструменти оголошує чужий сервер.
- [ ] Розрізняю tool, resource і prompt — і можу навести приклад кожного.
- [ ] Знаю, чого цей етап **не** обіцяє: що модель проігнорує ворожий текст в описі.

## Я пояснив

Не собі — вголос, іншій людині або в текст.

- [ ] **Чому опис інструмента з чужого сервера небезпечніший за його код?**
      Підказка: код ти не виконуєш, а опис іде в промпт.
- [ ] **Чому «сервер не піднявся» і «сервер замовк» — різні події?**
      Підказка: що ти робитимеш у кожному з двох випадків.

      Підказка: чим після цього відрізняється зламаний сервер від справного.
- [ ] **Чому MCP-інструмент — не ендпоінт?**
      Підказка: чого хоче модель — трьох викликів чи відповіді.
- [ ] **За що саме платиться тією секундою на виклик?**
      Підказка: дві речі, і жодна з них не швидкодія.

## Ручний чекліст: чужий сервер

Наш сервер свій, тож його поведінка передбачувана. Найцікавіше починається тут.

```bash
# Візьми будь-який публічний MCP-сервер і підключи client.py до нього
```

- [ ] **Подивись на сиру відповідь першою дією.** Чи є проза? Чи є блок узагалі?
- [ ] Скільки інструментів він оголошує? Пройди [`DECISION.md`](DECISION.md) по кожному:
      скільки з них насправді мали б бути параметрами?
- [ ] Чи придатні схеми для `tools=` без перетворень? Запиши, що довелося правити.
- [ ] **Прочитай усі описи очима.** Чи є серед них щось, що звучить як інструкція тобі, а не
      як опис дії? Це не паранойя: опис іде в промпт, і писав його не ти.
- [ ] Скільки з оголошених інструментів ти позначив би незворотними? Скільки з них позначив
      сервер? Різниця — це те, що `bridge.py` вирішує за тебе.
- [ ] Вимкни сервер посеред виклику (закрий процес руками). Яка фаза? Скільки чекав?
- [ ] Заміряй час одного виклику. Порівняй із секундою нашого демо — і подумай, чи ця різниця
      походить від протоколу чи від того, що робить сам сервер.
